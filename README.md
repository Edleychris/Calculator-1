# JavaScript Calculator Assignment

A beginner-friendly calculator built with HTML, CSS, and plain JavaScript.

## Run
Open `index.html` in any modern web browser. No installation required.

## Browser console tests
Open Developer Tools (F12) > Console and try:

```js
add(10, 5)          // 15
subtract(10, 5)     // 5
multiply(10, 5)     // 50
divide(10, 5)       // 2
operate('+', 12, 7) // 19
```

## Calculator tests
- Click 12 + 7 - 5 × 3 = to get 42 (evaluated left-to-right).
- Click 8 ÷ 0 = to see a friendly error.
- Click 1 . 2 . 3 to verify the second decimal is ignored.
- Press Clear to reset everything.
- Use Backspace to delete a digit.
- Use keyboard numbers, operators, Enter, Backspace and Escape.
